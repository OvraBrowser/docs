# Changelog

Changes that matter to developers, by Ovra version. For everything else, see **What's New** in the app.

## Ovra 1.0

- **New:** the [`.ovratheme`](/docs/formats/ovratheme) format (version 1) for sharing themes, with up to four colour stops, any direction, text style and effects.
- **New:** the [`.ovrabackup`](/docs/formats/ovrabackup) format (version 1) for backups.
- **New:** both file types are registered with macOS (`com.ovra.browser.theme`, `com.ovra.browser.backup`), so double-clicking opens them in Ovra.
- **New:** [debug launch arguments](/docs/contributing/build#debug-launch-arguments) for development and screenshots.
- **Changed:** updates are signed with a new EdDSA key.
