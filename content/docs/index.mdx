# Introduction

Ovra is a fast browser for the Mac, written in Swift on Apple's WebKit. These docs are for developers who want to build for Ovra or work on Ovra itself.

## What you can build

| | What | Status |
| --- | --- | --- |
| [Themes](/docs/formats/ovratheme) | Theme packs as `.ovratheme` files | <Status kind="available" /> |
| [Automation](/docs/automation) | Control Ovra with URLs, AppleScript and Shortcuts | <Status kind="planned" /> |
| [Ovra plugins](/docs/plugins) | Sidebar panels, toolbar buttons, commands and start page widgets in JavaScript | <Status kind="planned" /> |
| [Web Extensions](/docs/extensions) | Standard browser extensions | <Status kind="planned" /> |
| [Block lists](/docs/formats/block-lists) | Custom content-blocking lists | <Status kind="planned" /> |

Add-ons can be shared as files or, once it opens, through the reviewed Ovra gallery.

## Working on Ovra

The app is open on [GitHub](https://github.com/OvraBrowser/Ovra). Start with [Contributing](/docs/contributing) and [Build from source](/docs/contributing/build).
