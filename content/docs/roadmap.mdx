# Roadmap

What we're building for developers, in order. No dates — each step ships when it's ready.

| | Step | Status |
| --- | --- | --- |
| 1 | **File formats** — `.ovratheme` and `.ovrabackup` | <Status kind="available" /> |
| 2 | **Automation** — `ovra://` URL scheme, AppleScript, Shortcuts | <Status kind="planned" note="next" /> |
| 3 | **Plugin API** — sidebar panels, toolbar buttons, commands, start page widgets | <Status kind="planned" /> |
| 4 | **Web Extensions** — Manifest V3 through WebKit (Ovra will require macOS 15.4) | <Status kind="planned" /> |
| 5 | **Custom block lists** | <Status kind="planned" /> |
| 6 | **Ovra CLI** and a **samples repository** | <Status kind="planned" /> |
| 7 | **Ovra gallery** for reviewed add-ons | <Status kind="planned" /> |

Want something sooner, or something that isn't here? [Open an issue](https://github.com/OvraBrowser/Ovra/issues).
