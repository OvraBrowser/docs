# Plugin API reference

<Status kind="planned" />

This page will document every module, method, event and permission of the Ovra plugin API, with an example for each.

It will cover:

- **`manifest.json`** — name, version, permissions, entry points.
- **`ovra.tabs`** — read and open tabs, listen for tab changes.
- **`ovra.sidebar`** — register a sidebar panel.
- **`ovra.toolbar`** — add a toolbar button.
- **`ovra.commands`** — register commands and shortcuts.
- **`ovra.storage`** — store a plugin's own data.
- **`ovra.theme`** — read the current theme so your UI can match it.

Names and shapes above are working titles and may change. Have an idea or a need? [Open an issue](https://github.com/OvraBrowser/Ovra/issues) — the API is being designed now.
