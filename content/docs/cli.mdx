# Ovra CLI

<Status kind="planned" />

A small command-line tool for add-on developers.

| Command | What it will do |
| --- | --- |
| `ovra create` | Start a new extension, plugin or theme pack from a template. |
| `ovra validate` | Check a manifest, a block list or an `.ovratheme` file against the spec. |
| `ovra run` | Load your add-on into Ovra and reload it when files change. |
| `ovra pack` | Package an add-on into a single file, ready to share or submit to the gallery. |

Command names may change. Until it exists, validate theme files with the rules in [the `.ovratheme` format](/docs/formats/ovratheme#validation).
